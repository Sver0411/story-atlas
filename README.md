# 故事图谱 · Story Atlas

五十部作品的原创图文导读，在同一个书架中沿时间线阅读故事、沿关系网查阅人物。

[在线阅读](https://sver0411.github.io/story-atlas/) · [GitHub](https://github.com/Sver0411/story-atlas)

每本书只保留 **时间线** 与 **人物志** 两个页面。本站包含完整剧透，内容是独立撰写的情节概述，不是原文。

## 结构

```
index.html              书架
books/<id>/data.js      唯一内容源（事件、人物、关系、纪元）
books/<id>/index.html   时间线页面（由 tools/rebuild.py 生成）
books/<id>/characters.html  人物志页面（由 tools/rebuild.py 生成）
tools/rebuild.py        生成器
tools/check.py          链接与锚点检查
```

改内容只需要动 `data.js`，然后跑 `python3 tools/rebuild.py`。

## 说明

- 时间按事件实际发生的顺序排列，不按书的章节或出版顺序。
- 人物志里的关系网默认按家族/阵营分簇；点一个人，他会移到圆心，一阶、二阶依次展开。
- 部分长篇（水浒、战争与和平等）人物过多，关系网只取核心人物，卡片仍列全部。
