# 《魔戒》与《沙丘》内容口径

## 魔戒

36个事件、22位人物、37组直接关系，范围是托尔金小说三部曲（内部六部），含夏尔清洗与灰港。情节概述为原创撰写，资料链接列于书页末尾及数据 `sources` 中。

保留老林、汤姆·邦巴迪尔、古冢岗、格洛芬德尔接应、夏尔清洗等小说情节。亡者帮助清除南方海盗后获释；抵达米那斯提力斯的是阿拉贡与活人援军，不采用电影中亡灵军队直接清扫王城战场的安排。灰港结局与夏尔重建分别交代。

日期采用第三纪元纪年；`lr09` 的瑞文戴尔会议与护戒队出发跨越3018年秋冬，显示为“秋—冬”。并行战线按阶段衔接，不声称每一段叙述都是严格逐日发生。封面与插图呈现小说情境，未规定的容貌与景物细节为概念想象。

## 沙丘

32个事件、22位人物、40组直接关系，只收录弗兰克·赫伯特第一部小说。不把《沙丘救世主》等后作结局写入本书，也不采用近年电影改变的时间跨度与人物行为。

保罗与杰西卡在弗雷曼人中生活约两年。保罗初次正式驾驭沙虫的节点 `du24` 排在与哥尼重逢的 `du23` 之前，ID保留以稳定链接。阿莉娅已经出生，并在结局杀死男爵；保罗与契妮之子小莱托在袭击中死亡。政治婚约指向伊勒琅，契妮并未按电影结局离开。

水、香料、生态与信仰的因果均限于第一部小说揭示的范围。沙虫骑乘插图避免现代交通工具，弗雷曼人的地下储水池表现为隐蔽的巨大水藏；具体服装和洞窟形态属于概念设计。

两本书均不使用拼造的“原文名句”，不转载原著全文。页内来源含出版社/作者机构资料与供交叉核对的专门参考站，后者不作为原作的替代文本。
