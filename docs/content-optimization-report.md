## 五、原著依据

有明确章节定位的 137 个节点在页面上以「出处 · 章节」显示，`event.src` 字段可查。主要几类：

- **版本差异**：射雕按新修版回目（第 7、15—16、35、40 回）；冰与火限前三卷；福尔摩斯按《最后致意》原文。
- **关键反转**：嫌疑人 X（原著第 2、4、19 章，三条时间线）；白夜行（第 6、13 章与末章）；无人生还（第 15、16 章与手稿）。
- **争议年份**：白夜行全表统一 1973—1998（二十五年）；战争与和平补至 1820 尾声。

## 六、没有做完的部分

1. **没有逐句核对原文**。本轮以情节级核对为主，人物对白的措辞多为转述，不是原文引用。
2. **「有人说」「多年以后」类表述仍有残留**，全站扫描出 100 余处，多数是小说内部的传闻（如《百年孤独》《呼啸山庄》的乡里传言），少数尚未逐条判断。本轮只处理了明确编造人物后续的 20 余处。
3. **《三体》未动**。它是手写 HTML，本轮没有逐页校对；其中 68 个节点沿用早期内容，另有 `docs/content-review.md` 的结论可参考。
4. **26 部标「复核」的书只重读一遍**，没有对照原文修订；`monte-cristo`、`solitude`、`lotr`、`to-live` 等旧条目未在本轮处理。
5. **配图与图注未审**，53 部仍无插图。
6. **人物卡的组织**仍偏「身份 + 事迹」，没有完全按「初始身份 → 核心动机 → 关键选择 → 关系变化 → 最终命运」重写；本轮只改了与事实冲突的卡片。
