## 六、第二轮：结构与出处（本轮新做）

1. **出处落到节点。** `data.js` 的 event 支持 `src` 字段，`tools/rebuild.py` 会渲染成节点下方的「出处 · 章节」。已给 43 部书、137 个节点补了章节定位，主要是三处：争议年份（如白夜行的 25 年跨度）、版本差异（如射雕的版本与回目、冰与火限前三卷）、关键反转（如嫌疑人 X 的三条时间线）。没有把握的地方不写，宁可空着。
2. **人物卡给 3 个节点。** 原来只跳第一个事件，现在取首、中、末三个，按时间排序，一次改命、一次低谷、一次结局。
3. **事件与人物双向对齐。** 脚本统一跑了一遍：事件里出现的人补进其卡片，卡片上的人补进对应事件，人物的事件表按时间线顺序重排。补了 153 条事件侧、313 条人物侧，全站引用检查（缺卡、缺节点、关系端点、重复关系）为 0。
4. **八本局部修订补齐**：围城加订婚与两家议亲；白夜行全表统一为 1973—1998（二十五年）；龙纹身的地下室、马丁之死、哈丽特离岛三处改成同一版本；美国众神加冰岛尾声（另一个星期三）；第一律法的种子线改成"西行扑空、费罗私下取回"；飓光志结尾改到第二卷纳拉克；时光之轮结尾按第 14 卷（重新封印、身体互换）；猎魔人把斯提加城堡与利维亚骚乱拆成两节。
5. **正文英文残留清零**：全站 1325 个节点扫了一遍，剩下的 `MUGEN`（公司名）、`KACHE`（血字）、`KTV`、`SIM`、`Trolloc`（括注）是有意保留的。

## 七、仍然没做的

1. **`sources` 数组与链接**：目前只做了节点级章节文字，没有挂外部链接，也没有按审查建议做"原文／转述／待核"的三态标记。
2. **"仅被提及"的判断**：双向对齐是机械统一的，没有逐条判断某个背景人物是否该出现在事件里。这会让部分事件的参演人数偏多。
3. **配图**：53 部没有插图，`check.py` 只列名单。
4. **逐句校订**：全站正文仍是概述体，没有按原文逐句比对；审查报告里"逐句复核"的条目（如白夜行坠落、嫌疑人 X 物证）只做到了情节层面。
